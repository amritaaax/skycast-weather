# 🌦️ SkyCast Weather

A modern weather dashboard built with React, TypeScript, and Vite. SkyCast Weather provides real-time weather information, city search, location-based weather detection, extended forecasts, dark mode support, and a beautiful responsive user interface.

---

## ✨ Features

* 🔍 Search weather by city name
* 📍 Geolocation-based weather detection
* 🌡️ Real-time weather updates
* 📅 Extended weather forecast
* 🌙 Dark mode support
* 📱 Fully responsive design
* ⚡ Fast performance powered by Vite
* 🎨 Modern UI with light and dark themes

---

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* CSS3
* OpenWeather API
* Vercel

## 📂 Installation

Clone the repository:

```bash
git clone https://github.com/amritaaax/skycast-weather.git
```

Navigate to the project:

```bash
cd skycast-weather
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
